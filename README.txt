# Website Ulang Tahun Nabila Inggit

## Cara menjalankan
1. Buka `index.html` di browser.
2. Untuk musik, masukkan file musik yang kamu miliki secara legal ke:
   `assets/shape-of-my-heart.mp3`
3. Jika nama file berbeda, ubah nama pada bagian `<source>` di `index.html`.

## Catatan
Browser biasanya memblokir autoplay. Karena itu musik dicoba mulai setelah tombol
"Buka pesan" ditekan.

Website tidak memakai foto kenangan sehingga bisa langsung dipakai tanpa foto.
